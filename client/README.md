# Task Manager App

A task management application built with React and Redux Toolkit, with backend integration (Node.js, Express, MongoDB) planned as the next phase.

## Features
- ✅ Add tasks
- ✅ Delete tasks
- ✅ Mark tasks as complete/incomplete
- ✅ Persistent state using Redux Toolkit + localStorage
- ✅ Edit tasks
- ✅ Filter tasks by category and priority
- ⬜ Search functionality
- ⬜ Tailwind CSS styling


## Tech Stack
- Frontend: React (Vite), Redux Toolkit, Tailwind CSS
- Backend (planned): Node.js, Express, MongoDB

## Status
🚧 In development — core task management (add, delete, edit, filter, toggle) working with Redux Toolkit and localStorage. Styling and backend integration in progress.
## Getting Started

```bash
cd client
npm install
npm run dev
```
